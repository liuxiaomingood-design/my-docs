交互式代码教程

学习如何通过交互式步骤完成代码编写。

功能特点​

  • ✅ 左右分屏：左侧显示步骤说明，右侧显示代码
  • ✅ 实时跟随：点击步骤，代码自动更新
  • ✅ 语法高亮：支持多种编程语言的语法高亮
  • ✅ 步骤导航：清晰的步骤编号和状态指示

示例：HarmonyOS 应用开发​

下面是一个完整的交互式教程示例，展示如何创建一个简单的 HarmonyOS 应用界面。

操作步骤

1

删除 Index.ets 文件中 build 内的代码

首先，我们需要清理 build 方法中的默认代码，为添加新组件做准备。

2

删除无用的 message 变量

移除不再需要的 message 状态变量，保持代码简洁。

3

添加 Column 组件

在 build 方法中添加 Column 容器组件，用于垂直布局。

4

添加 Text 组件

在 Column 中添加 Text 组件显示欢迎文本。

5

添加 Button 组件

添加一个按钮组件，实现交互功能。

代码预览

步骤 1 / 5
📄Index.ets
@Entry
@Component
struct Index {
@State message: string = 'Hello World'

build() {
  // 这里将添加新的代码
}
}

使用方法​

1. 导入组件​

在你的 MDX 文件中导入 InteractiveTutorial 组件：

import InteractiveTutorial from '@site/src/components/InteractiveTutorial';

2. 定义步骤数据​

每个步骤包含以下属性：

  • title: 步骤标题
  • description: 步骤描述（可选）
  • code: 该步骤对应的代码

3. 使用组件​

<InteractiveTutorial
  steps={[
    {
      title: '步骤 1 标题',
      description: '步骤 1 的描述',
      code: `代码内容`
    },
    {
      title: '步骤 2 标题',
      code: `代码内容`
    }
  ]}
  language="typescript"
  filename="Example.ets"
/>

支持的编程语言​

组件支持所有 Docusaurus 支持的语法高亮语言：

  • TypeScript/JavaScript
  • Java
  • Python
  • C/C++
  • HTML/CSS
  • 等等...

自定义样式​

你可以通过修改以下文件自定义组件样式：

  • src/components/InteractiveTutorial/styles.module.css

下一步​

现在你已经学会了如何使用交互式教程组件，开始创建你自己的教程吧！
